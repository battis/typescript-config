# @battis/typescript-config

A collection of packages useful for setting up and managing TypeScript modules, especially those in monorepos.

## Packages

### [@battis/commit](./commit/README.md)

@battis's commit linting configuration

### [@battis/descriptive-types](./descriptive-types/README.md)

Towards domain-specific types for more legible code

### [@battis/eslint](./eslint/README.md)

@battis's [ESLint](https://eslint.org/) static analysis configuration

### [@battis/import-package-json](./import-package-json/README.md)

Import package files as typed objects locally or from [npm](https://npmjs.com)

### [@battis/monorepo](./monorepo/README.md)

@battis's monorepo configuration

### [monorepo-package-paths](./monorepo-package-paths/README.md)

Update workspace package manifests to use URLs relative to root package manifest

### [@battis/prettier](./prettier/README.md)

@battis's code formatting configuration (using [Prettier](https://prettier.io/))

### [@battis/toc](./toc/README.md)

Auto-generated package table of contents for monorepo README files

### [@battis/typescript-tricks](./typescript-tricks/README.md)

A handful of useful types and operators

### [@battis/webpack](./webpack/README.md)

Reusable, extensible webpack configurations for different needs

### [@battis/workspace](./workspace/README.md)

@battis's configuration for published monorepo workspaces
